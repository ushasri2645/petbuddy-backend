# PetBuddy
## Introduction

PetBuddy is a comprehensive mobile application for pet owners to manage their pets' care and health. It helps users stay organized with features like reminders, activity logs, and health records, ensuring pets receive the best care possible.

## Features of the App


### User Management

- Secure user authentication for account creation and login.
- Support for multiple pets within a single user profile.
- Pet Profile Management

### Pet Management
- Create and manage profiles for pets, including details like name, breed, age, and health records.
- Dedicated sections for feeding schedules, vaccination records, and health notes.

### Reminders

- Set reminders for medications, vaccinations, and vet appointments.

### Emergency Contacts

- Store contact details for veterinarians and pet services under the pet profile.
- One-click calling from the app.

### Activity Log

- Log daily activities like walks, playtime, and feeding schedules.
- Automatically update logs based on reminder notifications.

### Photo Gallery

- Upload and manage pet photos, creating a digital scrapbook.

### Integration with Pet Services

- Access local pet services (grooming, boarding, training) with contact details and reviews.

### Training Resources

- Explore articles, videos, and resources for pet training and behavior tips.

## Automated Build Workflow

- Continuous Integration/Continuous Deployment (CI/CD) processes using tools like GitHub Actions for seamless updates and deployment.

## Tech Stack
- Backend: Node.js, Express
- Database: MongoDB
- Testing: Jest, Supertest
